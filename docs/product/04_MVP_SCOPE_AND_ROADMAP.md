# MEANINGFRAME — MVP SCOPE & ROADMAP

## 1. Scope objective

Validate that Swiss customers will complete a guided meaning-based creation process and pay CHF 49 or CHF 229 after seeing a personalised preview.

The MVP must validate:

- customer understanding;
- session completion;
- preview quality;
- willingness to pay;
- physical-product demand;
- revision burden;
- emotional satisfaction;
- operational feasibility.

## 2. In-scope capabilities

### Public experience

- DE/EN landing pages
- responsive design
- pricing and example project
- trust, privacy, FAQ and legal pages
- campaign attribution

### Identity and project access

- no password required to start
- verified email magic link before free preview generation
- project resume
- authenticated project dashboard
- locale preference

### Co-Author Session

- recipient/self mode
- occasion selection
- adaptive structured conversation
- optional free text
- two to five photos
- upload validation, EXIF stripping and private storage
- autosave
- progress and resume
- skip optional questions

### Meaning Map

- structured Claude output validated against schema
- editable facts and exclusions
- confidence and missing-information handling
- explicit Co-Author confirmation
- immutable version snapshot used for generation

### Art direction and preview

- three Art Worlds
- recognisable artistic representation
- visual preference cards
- one protected personalised preview
- email verification and rate limit before generation
- watermark and reduced-resolution delivery
- regeneration only for documented technical failure

### Checkout and orders

- Digital Edition
- Signature Edition
- black or natural frame
- Stripe Checkout
- tax/shipping configuration for Swiss pilot
- webhook-driven order confirmation
- idempotency
- order history

### Paid creation

- three refined variants
- variant comparison
- select one
- one included guided revision
- additional revision purchase
- revision categories and structured instruction
- final approval
- Curator’s Note voice selection
- final artwork production

### Delivery

- secure time-limited downloads
- raster or vector output appropriate to Art World
- print-ready production file
- Curator’s Note PDF
- Certificate of Co-Creation PDF
- Reveal Page with private unguessable access
- optional recipient message authored or approved by Co-Author

### Signature fulfilment

- admin order queue
- production readiness checks
- production bundle download
- manual print-provider submission
- status tracking
- tracking-number entry
- customer notifications
- reprint/refund incident recording

### Privacy and safety

- consent records
- AI disclosure
- personal-use rights
- deletion controls
- automated retention jobs
- export of core project data
- content safety screening
- no-training policy
- vendor register
- operational audit events

### Analytics

- consent-aware product events
- funnel dashboard
- generation cost and latency
- conversion and edition mix
- revision/refund/fulfilment metrics
- no raw personal answers in analytics payloads

## 4. Product variants

### Art World A — Poetic Symbolism

- premium painterly raster output
- warm human-centred composition
- identity, symbols and atmosphere
- high-resolution print production

### Art World B — Modern Essence

- native vector preferred
- geometric, restrained, elegant
- clean paths and controlled palette
- SVG plus print PDF

### Art World C — Narrative Collage

- premium raster output
- layered life moments and symbolic anchors
- controlled density; no scrapbook effect
- high-resolution print production

## 5. Roadmap

### MVP

Swiss B2C launch as defined in this package.

### Evolution 1 — Conversion and automation

Trigger only after evidence:

- automate primary print-provider submission;
- add one additional size if requested by ≥ 20% of buyers;
- improve preview/generation model based on satisfaction data;
- contributor invitation without revealing the gift;
- automated referral credit;
- German market configuration.

### Evolution 2 — New product segments

- self-identity collection;
- couples/family collaborative project;
- company founder and team milestone art;
- retirement programmes for employers;
- professional photographer partner portal.

### Evolution 3 — Defensible platform

- proprietary style tuning using licensed/non-customer data;
- outcome-based art-direction recommendation;
- multi-provider generation routing;
- international fulfilment;
- premium human-artist collaboration clearly separated from AI editions.

## 6. Scope-change rule

A new feature enters the MVP only if it is:

1. required for legal or security compliance;
2. required to complete the primary paid customer journey;
3. required to measure a stated validation hypothesis; or
4. explicitly approved by the founder.

Everything else belongs in the backlog.
